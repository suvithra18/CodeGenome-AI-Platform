# 🚀 CodeGenome AI - Smart Student Skill & Placement Analytics Platform

## 📌 Overview

CodeGenome AI is an intelligent student performance analytics platform built using Django. It helps students evaluate their coding skills, interview readiness, resume quality, and placement preparedness through AI-powered analysis and personalized recommendations.

---

## ✨ Features

### 👨‍🎓 Student Management
- Student Registration
- Student Portfolio Dashboard
- Performance Tracking

### 💻 Coding Challenge Analyzer
- AI-based Coding Evaluation
- Automatic Score Calculation
- Personalized Feedback

### 🎤 AI Mock Interview System
- Dynamic Interview Questions
- Technical Answer Evaluation
- AI Feedback & Suggestions

### 📄 Resume Analyzer
- PDF Resume Upload
- Skill Extraction
- Resume Score Generation
- Improvement Suggestions

### 📊 Skill Analytics
- Logic Building Analysis
- Debugging Analysis
- Coding Speed Tracking
- Consistency Measurement

### 🏆 Leaderboard System
- Top Performer Ranking
- Skill-Based Comparison

### 📈 Placement Analytics
- Placement Readiness Score
- Career Role Prediction
- Placement Tracker

### 🔗 GitHub Integration
- GitHub Profile Analysis
- Repository Display

### 📑 Reports & Certificates
- PDF Report Generation
- Achievement Certificate Generation
